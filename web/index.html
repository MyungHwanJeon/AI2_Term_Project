    제출 전 확인사항

    원본 이미지 좌표와 데이터셋의 category ID를 유지하여 제출해 주시기 바랍니다.

    JSON 형식과 채점 기준

    예측 결과 형식

    JSON의 최상위 구조는 객체 목록입니다. 각 객체에는 image_id, category_id, bbox, score, segmentation을 포함해야 합니다.

    • bbox: 원본 이미지 기준 [x, y, width, height]
    • score: 0–1 범위의 유한한 신뢰도 값
    • segmentation: size: [height, width]와 압축 RLE 문자열 counts
    • category ID는 데이터셋의 원래 값을 사용해야 합니다. 0도 유효한 클래스 ID입니다.

    공정한 비교를 위한 기준

    • bbox와 mask를 각각 COCO AP@[.50:.95]로 평가합니다.
    • 두 AP의 산술평균을 최종 점수로 사용합니다.
    • 전체 테스트 이미지와 모든 카테고리를 대상으로 평가하며, area=all, maxDets=100을 적용합니다.
    • 학생별 최고 최종 점수 한 건만 리더보드에 반영합니다. 동점은 공동 순위로 표시하며, 이전 제출 기록은 보관합니다.
    • 동일한 파일을 다시 제출해도 제출 횟수에 포함됩니다. 동일 파일의 채점 결과는 재사용될 수 있습니다.
